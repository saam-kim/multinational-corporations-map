# 🌐 다국적 기업의 공간적 분업 (Global Division of Labor)

> **고등학교 통합사회 II. 세계화와 평화** 맞춤형 인터랙티브 지리 교육 웹애플리케이션  
> 디자인 레퍼런스: [sejong-gerrymandering-rebuild](https://github.com/saam-kim/sejong-gerrymandering-rebuild)

---

## 📖 프로젝트 개요

본 웹앱은 고등학교 통합사회 교과과정의 핵심 주제인 **'다국적 기업의 성장과 공간적 분업'**을 학생들이 직관적이고 능동적으로 탐구할 수 있도록 제작된 **수업용 인터랙티브 에듀테크(EdTech) 플랫폼**입니다.

대륙별 7대 대표 다국적 기업의 본사(HQ)와 연구개발(R&D), 생산 공장, 핵심 부품 기지를 고화질 표준 세계지도 위에 시각화하고, 각 거점이 **왜 그 지역에 입지했는지 3단계 입지 요인(비용, 정책, 클러스터)**을 심층 분석합니다.

---

## ✨ 주요 기능

### 1. 🗺️ 대륙별 7대 대표 기업 글로벌 공간적 분업 탐구
- **한국 / 아시아**: 🇰🇷 **삼성전자 (Samsung Electronics)** — 본국 초격차 R&D ⇄ 베트남·인도 조립 공장 ⇄ 미국 실리콘밸리·텍사스 AI/파운드리
- **북미**: 🇺🇸 **애플 (Apple Inc.)** — 캘리포니아 기획·설계 ⇄ 대만 TSMC 3nm 칩셋 위탁 ⇄ 중국·인도 폭스콘 대규모 조립
- **유럽**: 🇩🇪 **폭스바겐 (Volkswagen)** — 독일 본사 엔지니어링 ⇄ 동유럽 슬로바키아 SUV 조립 ⇄ 멕시코 대미 무관세 생산
- **중국 / 아시아**: 🇨🇳 **BYD (비야디)** — 선전 R&D 본사 ⇄ 중국 내륙 배터리 수직계열화 ⇄ 헝가리·태국 무역 장벽 극복 기지
- **남미**: 🇧🇷 **엠브라에르 (Embraer)** — 브라질 본체 설계·조립 ⇄ 미국 플로리다 전용기 맞춤 조립 ⇄ 포르투갈 복합소재 날개
- **오세아니아**: 🇦🇺 **BHP 그룹 (BHP Group)** — 호주 멜버른 투자 본사 ⇄ 서호주 필바라 자율 철광석 채굴 ⇄ 싱가포르 무역 허브
- **아프리카**: 🇿🇦 **사솔 (Sasol)** — 남아공 석탄액화(CTL) 플랜트 ⇄ 카타르 가스액화(GTL) 합작 ⇄ 미국 셰일가스 화학 단지

### 2. 🔍 3단계 입지 요인 심층 분석
- 거점 핀 및 칩 선택 시 **01 지리/인건비 요인**, **02 정부 정책/관세 혜택 요인**, **03 산업 인프라/클러스터 요인**으로 체계화된 설명 제공
- **📚 통합사회 교과서 핵심 포인트**: 수능 및 내신 빈출 개념 하이라이트 박스 탑재

### 3. ℹ️ 기업 상세 개요 & 분업 전략 인포그래픽 모달
- 상단 탭 클릭 시 기업 설립 연도, 글로벌 임직원 규모, 주력 사업 분야, 4대 거점 역할, 교과서 탐구 질문을 담은 글래스모피즘 모달 제공

### 4. 🎯 도전! 10문항 형성평가 퀴즈 모드
- 토스/듀오링고 스타일의 부드러운 진행도 프로그레스 바
- 정답(에메랄드)/오답(로즈) 즉각 피드백 및 상세 수능 연계 해설 창
- 최종 퀴즈 완료 시 등급 메달 및 점수 인포그래픽 카드 제공

### 5. ⛶ 수업 발표 모드
- 교실 빔프로젝터 및 전자칠판에 최적화된 전체화면 모드 지원

## 🛠️ 기술 스택

- **Core**: Pure HTML5, Modern CSS3, Vanilla JavaScript (ES6+)
- **Typography**: Pretendard WebFont
- **Map Engine**: Leaflet.js, D3.js v7
- **Map Tiles**: Esri World Light Gray Canvas & Reference (100% Free, No-API-Key, Zero Watermark)
- **UI Architecture**: Glassmorphism, Layered Elevation Shadows, Responsive Flex/Grid

## 🚀 실행 및 배포 가이드

### 1. 로컬 실행
별도의 빌드 도구나 Node.js 환경 없이 `index.html` 파일을 더블 클릭하여 웹 브라우저에서 바로 실행할 수 있습니다.

### 2. GitHub Pages 배포
1. 저장소 설정(**Settings**)으로 이동합니다.
2. 좌측 메뉴에서 **Pages**를 선택합니다.
3. **Branch**를 `master` 또는 `main`의 `/ (root)`로 지정하고 **Save**를 누릅니다.
4. 수초 내에 무료 배포 URL이 생성됩니다.

### 3. Vercel 배포
- 저장소를 Vercel에 연동하면 설정 없이(Zero-Config) 1초 만에 글로벌 CDN으로 배포됩니다.
